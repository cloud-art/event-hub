# Symfony API — WIP

Перед работой прочитать корневой `AGENTS.md` и документы затронутого требования.

- Обязательный стек: PHP 8.5, Symfony 8.1, PostgreSQL.
- API предназначен для Next.js и будущего мобильного приложения.
- Бизнес-правила мест, записи, оплаты и доступа принадлежат этому приложению.
- Контент поступает только из Битрикса через согласованный контракт.
- Для операций с местами явно определять транзакционную границу и защиту от конкуренции.
- Не выполнять медленные внешние запросы под блокировкой инвентаря мест.
- Проверять права организатора на конкретное мероприятие, включая экспорт.
- Для внешних операций учитывать повторы и неизвестный результат после таймаута.
- Redis не использовать как источник истины о местах.
- Схему, состояния, контракты и расположение модулей определить до реализации соответствующей задачи.
