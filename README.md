# EventHub

Локальный каталог демонстрационных мероприятий. Требуются Linux, Git, Make,
Docker Engine с Compose v2 и доступ в интернет при первой сборке.
PHP, Node.js, PostgreSQL и настройки `.env` на хосте не требуются.

```sh
make up
make check
make down
```

`make up` собирает контейнеры, применяет схему, импортирует мероприятия и
проверяет страницы. По умолчанию сайт доступен на `http://localhost:3000`,
API на `http://localhost:8080`. Порты доступны только локально. Для других
портов задайте `WEB_PORT` и `API_PORT`; при автономном Compose задайте
`COMPOSE` равным пути к его исполняемому файлу. `make down` сохраняет том БД.

Если запуск не удался, смотрите первый неготовый шаг: сборка, подготовка БД,
импорт, API или сайт. `make check` возвращает ошибку, если источник недоступен,
нет опубликованных событий либо страницы не показывают импортированный контент.

## Чтение мероприятий

- `GET /api/v1/events` возвращает массив опубликованных мероприятий, пустой
  массив `[]`, если их нет. Поля: `id`, `title`, `description`, `city`, `venue`,
  `startsAt` (время со смещением), `timezone`, `program` и `speakers` (списки строк).
- `GET /api/v1/events/print-studio` возвращает тот же объект. Например,
  `id: "print-studio"`, `title: "Студия печатной графики"`, `timezone: "Europe/Moscow"`.
  Неизвестный ID и `draft-session` возвращают одинаковый HTTP 404 с `{"error":"not_found"}`.

## Область проверки

Для OPS-005, CMS-004, CAT-001, EVT-001 и API-001 проверен только локальный путь:
временный HTTP-источник → PostgreSQL через импорт Symfony → API → каталог и карточка.
На чистой копии файлов без установленных зависимостей и новом томе `make up`
загрузил три записи, две публичные. После `make down` и повторного запуска
идентификаторы базы и таблицы и число записей сохранились. Chromium при ширине
360 пикселей показал программу, спикера, площадку и часовой пояс. Пустой каталог,
ошибка API и неизвестный ID проверены отдельно. Отказ источника даёт ошибку проверки.

Битрикс, двойники, запись, остаток мест и оплата не входят в этот сценарий.
Формат локального источника не является контрактом Битрикса.
