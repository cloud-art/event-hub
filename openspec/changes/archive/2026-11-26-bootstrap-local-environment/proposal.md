# Proposal

## Why
Сейчас есть только документы и каркас приложений. Чтобы проверить первый сквозной путь
данных, нужна воспроизводимая локальная основа, не зависящая на этом шаге от установки
Битрикса. Это промежуточный результат на пути к OPS-005, а не выполнение OPS-005.

## What Changes
- Одна локальная команда поднимает PostgreSQL, Symfony API, Next.js и временный
  источник демонстрационного контента без ручной установки приложений.
- Контент поступает в Symfony через отдельную границу получения контента; сайт читает
  список и страницу мероприятия только через Symfony API.
- Документируются адреса, проверка готовности и повторный запуск без потери данных.

Граница первого сценария: публичный базовый каталог и страница мероприятия с
тестовым контентом; без записи, оплаты, учёта свободных мест, поиска/фильтров,
полной локализации, двойников, ролей, Unleash и нагрузочной готовности.
Затронуты OPS-005, TECH-001, API-001, CAT-001, EVT-001, CMS-004; эти требования
в целом данным change не закрываются. CMS-001, CMS-003, CAT-002–CAT-003,
EVT-002 и TECH-003 остаются для следующих изменений.

Кирилл разрешил временно заменить Битрикс мок-источником **только для разработки
первого сценария**; это пересматривает порядок из INT-035, но не исходное ТЗ и не
является согласованием клиентом замены Битрикса. Перед итоговой приёмкой нужны
настоящий Битрикс с контентом, получение данных из него, доставка двойников и
полный чистый запуск. Q-010 и Q-011 открыты; способ установки/доставки ещё не выбран.

## Capabilities

### New Capabilities
- `local-environment`: локальная подготовка, запуск и проверка готовности первого сценария.
- `event-discovery`: публичный просмотр списка и страницы мероприятия через Symfony API.

### Modified Capabilities
Нет: существующие спецификации отсутствуют.

## Impact
Планируются корневые команды и Compose, `infra/`, `apps/api/`, `apps/web/`,
локальный мок-источник, примеры конфигурации и инструкция запуска. Появятся
минимальные публичные API чтения контента и страницы сайта. Битрикс и двойники
в этот состав не входят; бизнес-API записи и оплаты не определяются.
